# iKPace Images Directory

This directory contains images for the iKPace platform.

## Required Images:
1. logo.png - Platform logo
2. favicon.ico - Browser favicon
3. hero-bg.jpg - Hero section background
4. course-placeholder.jpg - Default course image
5. avatar-placeholder.png - Default user avatar

## For Now:
Use placeholder images from:
- https://ui-avatars.com/api/ for avatars
- https://picsum.photos/ for general images
- https://placeholder.com/ for placeholders

To create actual images, you can use:
1. Canva for design
2. Unsplash for free stock photos
3. Remove.bg for transparent backgrounds
